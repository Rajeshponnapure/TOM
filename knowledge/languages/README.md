frameworks, tooling, build systems, testing, and deployment.

## Language-Agnostic Concepts

Tom applies these universally across ALL languages:
- Design patterns (Singleton, Factory, Observer, Strategy, etc.)
- SOLID principles (Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion)
- Clean Code (meaningful names, small functions, no side effects, DRY)
- Testing (TDD, unit/integration/E2E, mocking)
- Performance (profiling, caching, lazy loading, parallel computing)
- Security (input validation, output encoding, authentication, authorization)
- Documentation (docstrings, README, API docs, architecture decisions)
- Version Control (git flow, conventional commits, semantic versioning)
- CI/CD (automated builds, tests, deployment, monitoring)
