# Media Production & Editing Skills

## Video Editing

### Adobe Premiere Pro
- **Interface**: Source monitor, program monitor, timeline, project panel, effects control
- **Editing Workflow**: Import → organize → rough cut → fine cut → transitions → effects → color → audio → titles → export
- **Timeline Editing**: Razor tool, ripple edit, rolling edit, slip/slide, rate stretch
- **Multicam**: Sync by timecode/audio, switch angles, flatten
- **Color Correction**: Lumetri Color panel, basic correction, curves, color wheels, HSL secondary, vignette
- **Audio**: Essential Sound panel, track mixer, audio transitions, noise reduction
- **Titles & Graphics**: Essential Graphics panel, templates, motion graphics (.mogrt)
- **Export**: Media Encoder, H.264/5, ProRes, DNxHD, master files, social presets
- **Keyboard Shortcuts**: C (razor), V (selection), Q/W (ripple trim), R (rate stretch), ~ (full screen)

### DaVinci Resolve
- **Cut Page**: Fast editing, smart reframe, speed editor support
- **Edit Page**: Timeline editing, transitions, effects, titles, Fusion comps
- **Fusion Page**: Node-based compositing, particles, text, 3D, tracking, keying
- **Color Page**: Node-based grading, color wheels, curves, power windows, tracking, HDR grading, LUTs, stills
- **Fairlight Page**: Multi-track audio, mixing, EQ, dynamics, effects, recording, ADR
- **Delivery Page**: Export settings, render presets, batch export

### Final Cut Pro X
- Magnetic Timeline, connected clips, compound clips
- Roles for organizing audio/video
- Multicam with angle viewer
- Color grading with color board
- Proxy workflow for 4K/8K

## Visual Effects

### Adobe After Effects
- **Compositing**: Layer-based, pre-comps, adjustment layers, blend modes
- **Keyframes**: Position, scale, rotation, opacity, effects
- **Expressions**: loopOut(), wiggle(), time*value, linear(), ease()
- **Tracking**: Point tracker, planar (Mocha AE), 3D camera tracker
- **Masking**: Shape masks, rotobezier, mask tracking
- **Particle Systems**: Particular, Form, CC Particle World
- **Text Animation**: Range selectors, per-character 3D, text animators
- **Rendering**: Render Queue, Media Encoder, multi-machine
- **Integration**: Dynamic Link with Premiere Pro, C4D integration

### Nuke
- Node-based compositing
- Keyers: Primatte, IBK, keylight, difference key
- Rotopaint: Clone, reveal, blur tools
- Tracking: Planar, point, camera tracker
- Deep compositing for stereoscopic/VFX

## Color Grading
- Color Theory: Hue, saturation, luminance, complementary, triadic
- Primary Correction: Lift/gamma/gain, contrast, white balance
- Secondary Correction: HSL qualification, power windows, tracking masks
- HDR Grading: PQ/ST.2084, HLG, Dolby Vision, HDR10+
- LUTs: 1D LUT, 3D LUT, creating LUTs, applying LUTs
- Scopes: Waveform, vectorscope, histogram, parade
- Skin Tone: Hue vs saturation, offset, key color
- Matching Shots: Shot match tool, manual matching by scopes
- Film Emulation: Kodak, Fuji, bleach bypass

## Audio Production

### Pro Tools
- Recording, editing, comping, elastic audio
- Mixing: Inserts, sends, subgroups, VCA, automation
- Surround sound: 5.1, 7.1, Atmos

### Adobe Audition
- Spectral editing, noise reduction, adaptive noise reduction

- Mastering: EQ, compression, limiting, maximizing

### Audio Mixing
- EQ: Parametric, graphic, shelving, high/low pass

## 3D Modeling & Animation

### Blender
- **Modeling**: Mesh editing, modifiers (subdivision, mirror, solidify), sculpting, retopology
- **Texturing**: UV unwrapping, shader editor (Principled BSDF), PBR textures, image textures
- **Rigging**: Armatures, bone constraints, IK/FK, weight painting
- **Animation**: Keyframes, graph editor, NLA editor, action editor, shape keys
- **Rendering**: Cycles (path traced), Eevee (real-time), render settings, compositing
- **Geometry Nodes**: Procedural modeling, fields, attributes
- **Grease Pencil**: 2D animation in 3D space
- **Physics**: Cloth, rigid body, fluid, smoke, particles

### Autodesk Maya
- Poly modeling, NURBS, subdivision surfaces
- Rigging: Joints, IK handles, skinning, constraints
- Animation: Keyframes, graph editor, animation layers
- Dynamics: nCloth, nParticles, nHair, Bullet physics
- Rendering: Arnold, Maya Software, mental ray

### Cinema 4D
- Modeling: Poly modeling, generators, deformers
- MoGraph: Cloner, effector, fracturing, motion graphics
- Animation: Keyframes, curves, character tools
- Rendering: Physical, Redshift, Octane, Arnold
