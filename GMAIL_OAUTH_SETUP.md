# Gmail OAuth2 Setup Guide

This guide explains how Gmail authentication works in TOM and what the two credential files mean.

---

## Quick Summary

The TOM agent sends PDF reports via **Gmail OAuth2** (secure, no password needed).

**Two files are required:**

| File | What It Is | Where It Comes From | Editable? |
|------|-----------|-------------------|-----------|
| `google-credentials.json` | OAuth 2.0 Client secret from Google Cloud Console | **You download it** from Google Cloud | ❌ Never edit |
| `google-credentials_token.json` | Cached OAuth access token | **Auto-generated by TOM** on first login | ❌ Never edit |

---

## How It Works: The OAuth2 Flow

```
Step 1: First Run
├─ TOM loads google-credentials.json ✓
├─ TOM detects no gmail_token.json exists yet
└─ TOM opens your browser → Google sign-in page

Step 2: You Authenticate
├─ You sign in with your Gmail account
├─ You grant TOM permission to send emails
└─ Browser redirects back to TOM

Step 3: Token Saved
├─ TOM saves OAuth token to google-credentials_token.json
├─ This file now contains cached access token
└─ Future runs: TOM uses saved token (no more sign-in!)

Step 4: Token Refresh (Automatic)
├─ If token expires, TOM auto-refreshes it
├─ No action needed from you
└─ Token file updates automatically
```

## Step 1: Set Up Google Cloud Console

### 1.1 Create a Google Cloud Project

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Click the project dropdown at the top
3. Click "NEW PROJECT"
4. Name it: `tom-agent` or any name you like
5. Click "CREATE" and wait a few seconds

### 1.2 Enable Gmail API

1. In the search bar, type `Gmail API`
2. Click the first result
3. Click "ENABLE" button
4. Wait for it to load (may take a moment)

### 1.3 Create OAuth Credentials

1. Click "Create Credentials" button (top right)
2. **Application type:** Select "Desktop application"
3. **Name:** Enter `TOM Agent` or similar
4. Click "CREATE"
5. A popup appears showing your credentials
6. Click "DOWNLOAD" (right side) to download as JSON

### 1.4 Place the File

The downloaded file will be named `client_secret_*.json` or similar.

**Rename it to:** `google-credentials.json`

**Place it here:** `C:\Users\saimo\tom_autonomous_agent\google-credentials.json`

✅ **Done!** Your `google-credentials.json` is ready.

## Troubleshooting

### "No such file: google-credentials.json"

**Problem:** TOM can't find your credentials file.

**Fix:**
1. Go to Google Cloud Console → Download credentials again
2. Rename to `google-credentials.json`
3. Place in: `C:\Users\saimo\tom_autonomous_agent\`
4. Try again

### "Invalid grant" Error

**Problem:** Token expired or invalid.

**Fix:**
1. Delete `google-credentials_token.json`
2. Run agent again
3. Sign in when browser opens (TOM will create new token)

### Browser Doesn't Open

**Problem:** TOM can't open your browser for sign-in.

**Fix:**
1. Check that Chrome is installed at: `C:\Program Files\Google\Chrome\Application\chrome.exe`
2. Or manually navigate to the URL TOM prints in console
3. Copy the URL from terminal and paste into browser

### Email Not Sending

**Problem:** Agent can't send email.

**Possible Causes:**
- Gmail credentials not valid → Delete token file and re-authenticate
- Email address wrong → Check `EMAIL_ADDRESS` in .env matches your Gmail account
- Gmail account security → You might need to enable "Less secure apps" (for older Google accounts) or use App Passwords (for 2FA accounts)

**Fix:**
1. Delete `google-credentials_token.json`
2. Re-authenticate (run agent, sign in when prompted)
3. Try sending again

## Security Notes

✅ **What's Secure:**
- OAuth2 is secure (no password stored)
- `google-credentials.json` should be kept secret (don't commit to git, don't share)
- `google-credentials_token.json` is auto-managed by TOM (never edit manually)

⚠️ **What to Do:**
1. Add to `.gitignore`:
   ```
   google-credentials.json
   google-credentials_token.json
   ```
2. Never share these files
3. If you accidentally commit them, regenerate new credentials from Google Cloud

## Reference: File Formats

### google-credentials.json (Example)

```json
{
  "type": "desktop",
  "client_id": "123456789-abc.apps.googleusercontent.com",
  "client_secret": "your_secret_key_here",
  "redirect_uris": ["urn:ietf:wg:oauth:2.0:oob"],
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token"
}
```

### google-credentials_token.json (Auto-Generated)

```json
{
  "token": "ya29.a0AfH6SMBx...",
  "refresh_token": "1//0gU...",
  "token_uri": "https://oauth2.googleapis.com/token",
  "client_id": "123456789-abc.apps.googleusercontent.com",
  "scopes": ["https://www.googleapis.com/auth/gmail.send"]
}
```

**DO NOT EDIT** - TOM manages this automatically.
